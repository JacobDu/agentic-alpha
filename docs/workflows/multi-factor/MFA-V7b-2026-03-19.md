## 4. Interpretation

The optimal short-hold configuration is **plain TopkDropout with `hold_thresh=20, n_drop=1`**.

**Why this works:**
1. `hold_thresh=20` forces ~20 day minimum hold, allowing positions to develop while maintaining responsiveness
2. `n_drop=1` (sell only 1 stock per day) dramatically reduces turnover and transaction costs
3. The combination creates a "patient momentum" effect - positions are given time to work, exits are gradual

**Why TrueBufferExit failed with min_hold=5:**
- 5-day minimum hold is too short for the buffer mechanism to add value
- High turnover (~18%) erodes most of the alpha
- Plain TopkDropout with hold_thresh already provides sufficient exit discipline

## 5. Decision

**Promote**

`TopkDropoutStrategy(topk=20, n_drop=1, hold_thresh=20)` is promoted as the new SOTA for short-hold strategies.
